Click the button to view a PDF document generated by JavaScript PDF Library. Please note that Adobe Reader or its equivalent is required to view the resultant document.

This sample demonstrates the creation of simple PDF document. It draws the string 'Hello world!!!' in the desired location using PDF standard font.

It is also possible to draw different language of text with different fonts using TrueType fonts and CJK fonts.
