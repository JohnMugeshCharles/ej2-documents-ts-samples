This sample demonstrates how to import and export Excel files while skipping specific properties to optimize performance in the Spreadsheet component.

This sample demonstrates how the Spreadsheet component can efficiently import and export Excel files by selectively skipping non-essential properties. These parsing and serialization options are designed to enhance performance, particularly when dealing with large or complex Excel workbooks. Excel workbook files can be imported and exported by providing openUrl & saveUrl property.

During the import and export processes, you can configure the parsing and serilazation options to ignore specific properties such as styles, charts, images, formulas, and more. These options can be dynamically set using the beforeOpen and beforeSave events, allowing users to tailor the behavior based on file contents.

Available Options:

  • ignoreStyle: Skips cell styling such as font, color, borders, and alignment.
  • ignoreFormat: Skips number formatting rules (e.g., currency, date formats).
  • ignoreChart: Skips embedded chart objects.
  • ignoreImage: Skips image objects embedded in the worksheet.
  • ignoreMergedCell: Skips merged cell information.
  • ignoreFormula: Skips formula cells and imports only the last calculated values.
  • ignoreValidation: Skips data validation rules such as dropdowns or constraints.
  • ignoreConditionalFormat: Skips conditional formatting rules that apply styles based on cell values.
