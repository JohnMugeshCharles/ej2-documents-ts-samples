This example demonstrates Word document comparison in the Document Editor. Upload two documents and click "Compare" to view differences as tracked changes.

This example showcases Word document comparison capabilities in the Document Editor, including:

  • Upload and compare two versions of Word documents in DOCX or SFDT format.
  • Compare documents using the Syncfusion .NET Word Library (DocIO) on the server side.
  • View the comparison result in the Document Editor with differences highlighted as tracked changes.
  • Download the compared document with tracked changes preserved.

More information about the document editor features can be found in this documentation section.
