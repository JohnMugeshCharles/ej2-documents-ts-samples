This sample demonstrates the text extraction features of PDF Viewer such as extracting text from the entire PDF document, a specific page, or a selected area, and copying the extracted text to clipboard.

The PDF Viewer component enables you to extract text content from PDF files. This sample demonstrates:

  • Extract text from the entire PDF document
  • Extract text from a specific page
  • Extract text from a selected area using the Select Area toolbar button
  • Copy extracted text to clipboard
  • Core interactions — Scrolling, Zooming, Panning and Page Navigation

More information on the PDF Viewer text extraction features can be found in this documentation section.
