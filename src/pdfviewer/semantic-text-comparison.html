This sample showcases the Semantic Text Comparison feature of the PDF Viewer component, enabling users to compare two PDF documents and identify textual differences. The PdfComparer provides an intuitive interface with synchronized viewers and a differences panel for efficient document comparison.

This sample demonstrates the PdfComparer of the PDF Viewer, which allows side-by-side comparison of two PDF documents. Key features include:

  • Synchronized Viewers — Navigate, zoom, and scroll both documents simultaneously for seamless comparison.
  • Differences Panel — View a consolidated list of all detected differences categorized as added, deleted, or replaced.
  • Intelligent Highlighting — Textual differences are highlighted directly within the documents using color-coded annotations.
  • Interactive Navigation — Click on any difference in the panel to automatically navigate both viewers to the relevant page and highlight the specific content.
  • Customizable Colors — Configure before/after colors and opacity levels to suit your viewing preferences.
  • Toggle Highlights — Enable or disable highlight display without losing comparison data.

The comparison categorizes differences as follows:

  • Added — Content newly introduced in the target document.
  • Deleted — Content removed from the source document.
  • Replaced — Content that has been modified between the source and target documents.

This functionality is invaluable for document reviews, contract validation, version control tracking, compliance auditing, and collaborative editing workflows.
