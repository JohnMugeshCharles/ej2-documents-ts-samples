This sample demonstrates role-based access control in the PDF Viewer. The User dropdown allows switching between Admin, User, and Read-Only User roles. When a document is loaded, the permissions associated with the selected role are applied dynamically to the viewer.

  • Admin: Has full access to annotations, form fields, text selection, page organization, download, and all toolbar actions.
  • User: Can create annotations, edit their own annotations, and reply to annotations created by others. Annotations created by other users remain locked.
  • Read-Only User: Can view documents and annotations only. Annotation creation and modification, form interactions, text selection, download, and page organization are restricted. The toolbar is limited to viewing and navigation tools.

Role-based access is managed through PDF Viewer APIs such as annotationSettings, formFieldCollections, toolbarSettings, enableDownload, and enablePageOrganizer, which control annotation permissions, form field access, toolbar availability, document download, and page organization features. The viewer UI is updated immediately whenever the active role changes.

For more information about configuring and managing role-based permissions in the PDF Viewer, refer to the PDF Viewer Permissions documentation.
